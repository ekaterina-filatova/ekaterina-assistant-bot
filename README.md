🤖 Ассистент Екатерины — Telegram-бот для записи на консультацию
Telegram-бот для специалиста по нейросетям и автоматизации бизнеса:каталог услуг, ответы на частые вопросы и автоматическая записьна бесплатную консультацию с мгновенным уведомлением администратору.

▶ Живой бот: @filatovaneirobot

✨ Возможности
🛠 Каталог услуг — 5 карточек с описанием, сроками и результатом (inline-клавиатуры)
❓ FAQ — ответы на частые вопросы в один клик
📅 Сценарий записи (FSM) — имя → способ связи → контакт → задача → подтверждение
✅ Валидация ввода — @ник Telegram (regex), телефон (request_contact или текст +7…)
📬 Уведомление админу — заявка мгновенно приходит в личные сообщения
💾 Хранение заявок — JSON-файл с датой и временем
🧯 Устойчивость к ошибкам — fallback-обработчики, подсказки при неверном вводе
🧰 Стек
Python 3.13
aiogram 3 (asyncio)
FSM: StatesGroup, MemoryStorage
Хранение: JSON
🚀 Запуск
git clone https://github.com/ВАШ_ЛОГИН/ekaterina-assistant-bot.gitcd ekaterina-assistant-botpip install -r requirements.txt
Создайте бота у @BotFather — получите токен
В начале bot.py впишите TOKEN и ADMIN_ID (свой ID: команда /myid у бота)
Запустите: python bot.py
