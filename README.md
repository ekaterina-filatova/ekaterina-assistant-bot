# 🤖 Ассистент Екатерины — Telegram-бот для записи на консультацию

Телеграм-бот для специалиста по нейросетям: каталог услуг, ответы на частые вопросы и автоматическая запись на бесплатную консультацию с мгновенным уведомлением администратора.

▶ Живой бот: [@filatovaneirobot](https://t.me/filatovaneirobot)

## ✨ Возможности

- 🛠 Каталог услуг — 5 карточек с описанием, сроками и результатом
- ❓ FAQ — ответы на частые вопросы в один клик
- 📅 Сценарий записи (FSM): имя → способ связи → контакт → задача → подтверждение
- ✅ Валидация ввода: @ник Telegram (regex), телефон (кнопка или текст +7…)
- 📬 Уведомление администратора о каждой заявке
- 💾 Сохранение заявок в JSON
- 🧯 Fallback-обработчики: бот подсказывает при любом неверном вводе

## 🧰 Стек

Python 3.13 · aiogram 3 (asyncio) · FSM (StatesGroup, MemoryStorage) · JSON

## 🚀 Запуск

1. Создайте бота у @BotFather — получите токен
2. Узнайте свой Telegram ID — команда /myid у бота
3. В начале файла bot.py впишите TOKEN и ADMIN_ID
4. Установите зависимости и запустите:

- `pip install -r requirements.txt`
- `python bot.py`
